poidh deadlines

poidh has no on-chain deadline, so bounties state one in their description, or do not. This page reads every open bounty, pulls the date out of the text, and puts it on a calendar. Refreshes every 6 hours from open scripts.

Open bounties with no stated deadline

These are open right now but the description never says when they close. Newest first. If you issue bounties: write the date and a timezone in the description, it is the only place anyone can read it.

How it works

scripts/scan-poidh-deadlines.py pages through poidh's live bounty feed and parses dates like "August 24, 2026" or "11:59 pm PT Sun Jun 14" out of each description. build-bounty-dashboard.py adds amounts, USD, chain, and a task-type guess. Nothing here is read from a structured deadline field, because across every open bounty scanned, none set one. poidhz is built by BetterCallZaal / The ZAO for poidh. MIT, fork it.

Data: bounty-dashboard.json (6h refresh), poidh-deadlines.ics. Last refresh: loading.
