# Day 2 - the NAMED-ROOM variant. ZAAL'S CALL, NOT A DECISION.

**Drafted 2026-09-21 on the zaoonparagraph lane's go-ahead. Not generated, not cast, and not
the default.** The default day 2 is `rounds/daily/generated/t-11-2026-09-22-a.md`. This file
is that one with a single change to THE BAR, so the two can be compared line for line.

## The one change

The default says "Post it publicly" anywhere, plus "Tag @bettercallzaal on X and cross-post in
the /poidh channel" as a requirement. This says: **post it in ONE place - the /zao channel -
and claim it here.** Tagging is dropped as a requirement, which matches day one.

## Why

`docs/how-bounties-got-shared-2026-09-21.md`, finding b. Bounties that named one room for the
entry to be posted in drew a median of 11.5 entries against 3, and it held on non-photo asks.
Each entry becomes a public post in the same place, so the room fills up and the people in it
see the bounty working. **n=10 of 600. Suggestive, not proven** - which is why this is a
variant and not the template.

## The trade-off Zaal has to weigh

**A Farcaster room excludes everyone not on Farcaster - and the Maine audience the festival
needs most mostly is not.** The fallback line ("Not on Farcaster? Post it anywhere public")
keeps them eligible, but their entries will not land in the room, so the effect finding b is
about only works for the Farcaster half.

**/zao or /poidh?** /zao is our own community. /poidh has 5,681 followers who already expect
bounties there. Every example in finding b used a room tied to the ASK (/football for a World
Cup ask, /inflynce for an Inflynce ask), which argues for /zao. It is a guess either way.

**Whichever is chosen, the description is immutable once cast.**
